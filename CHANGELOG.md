# Changelog

## 1.0.0-rc.1 — candidata a lançamento

Esta versão reúne a aventura jogável da branch principal e prepara sua distribuição.
O rótulo de candidata não substitui uma avaliação com jogadores.

- Duas rotas de fuga, aliados com consequências e recursos limitados.
- Combate com munição, cura, recuo e estado persistente dos inimigos.
- Saves JSON versionados, gravação atômica e leitura validada de saves antigos.
- Testes de regras, persistência e percursos reais pelo terminal.
- Identificação com `--version`, guia de primeira partida e demonstração automatizada.
- Empacotamento em ZIP com checksum, sem saves pessoais ou dependências de execução.

## Antes de promover para 1.0.0

- Observar ao menos uma primeira partida sem orientar o jogador.
- Conferir navegação, inventário, salvar/carregar e compreensão dos custos.
- Verificar as execuções Linux/Windows do CI após o merge.
- Registrar problemas de dificuldade/clareza e decidir se exigem correção.

Nenhum tag ou GitHub Release é publicado automaticamente por este preparo.

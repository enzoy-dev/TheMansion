# TheMansion

TheMansion é um jogo de terror e sobrevivência baseado em texto, desenvolvido em Python.

O projeto começou como um jogo simples em Python e evoluiu para um sistema mais completo, com exploração, combate, inventário, armas, inimigos, diálogos e salvamento de progresso.

## Funcionalidades

* Sistema de exploração
* Sistema de combate
* Inventário e gerenciamento de itens
* Armas e munição
* Inimigos
* Sistema de diálogos
* Sistema de estado e progressão
* Salvamento em JSON

## Tecnologias

* Python
* Programação Orientada a Objetos
* JSON
* Git

## Como executar

Clone o repositório:

```bash
git clone https://github.com/enzoy-dev/TheMansion.git
```

Entre na pasta:

```bash
cd TheMansion
```

Execute o jogo:

```bash
python TheMansion.py
```
